# Ada-Bot

Ada-Bot is an AI-powered Discord news assistant that automatically fetches and summarises the latest AI research and industry updates, posts interactive news digests to Discord, and answers user questions through a Retrieval-Augmented Generation (RAG) pipeline using contextual semantic retrieval.

## Features
- Fetches AI news and research updates automatically twice daily.
- Generates concise AI-powered summaries for articles.
- Filters duplicate and highly similar news articles.
- Performs sentiment analysis on news content.
- Posts formatted news digests directly to Discord channels.
- Creates dedicated discussion threads for each article.
- Allows users to interact with the bot using @Ada.
- Answers user questions using contextual article retrieval.
- Provides grounded responses with relevant source links.
- Stores processed article knowledge for future retrieval.
- Supports semantic search across previously fetched articles.
- Maintains an evolving AI-news knowledge base.
- Enables community discussion around AI news topics.
